# Amendment 2 (after code review, before any run)

The Critic's code review found that the spread-ratio threshold comparison was decided by floating-point noise on exact ties (spreads are quantised at 0.1 pip, so a ratio of exactly 2.0 is common; 37 of 106 tie bars on USDJPY were dropped). The module now compares ratio >= spread_ratio_min * (1 - 1e-9). The registered sanity counts came from the same float comparison and are corrected here, from counts only, before any backtest: USDJPY hypothesis cell 160 episodes on 123 trading days (was 135 on 105), move_atr_min 0.4 cell 83 (was 76), news-included control 567 (was 522), 271 at 0.4 with news; ratio-0 controls unchanged (2075 / 549 / 3576 / 1162); EURUSD 64, GBPUSD 35, AUDUSD 24, EURJPY 41, GBPJPY 37, AUDJPY 17, XAUUSD 82 (non-primary pool about 300, was 285). Expected design t restated as 1.3-1.6 trade-level (expected_design_t_min 1.3); the 120-episode floor in kill rule 1 is unchanged. Cost stress re-runs the signals on widened spreads and keeps the sample nearly fixed after the fix (160 -> 162 at 1.5x, 163 at 2x); stress rows are read as near-identical samples.
